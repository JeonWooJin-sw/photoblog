# PhotoBlog

2026-2 모바일/웹서비스 프로젝트 공통평가 01

Django로 만든 포토블로그 서버와, 서버와 연동되는 안드로이드 앱.
앱에서 사진과 글을 올리면 블로그에 게시되고, 동기화하면 서버의 글과 사진을 받아와서 보여준다.

```
photoblog/
├── PhotoBlogServer/   Django 서버 (REST API, 테스트, API 검증 엔진)
├── PhotoViewer/       Android 클라이언트 (Java)
└── 모바일웹서비스 프로젝트 공통평가 01_수행 결과 보고서.docx
```
